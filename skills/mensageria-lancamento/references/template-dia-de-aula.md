# Template de Dia de Aula: Dois Modelos Completos

Perguntar ao usuário qual modelo usar. Se horário entre 6h-12h: modelo manhê. Se 17h-22h: modelo noite.

## Aulas 2 a 5 (modelo manhê, com gravaçêo do dia anterior)

Mesma estrutura da Aula 1, com uma diferença: a gravaçêo do dia anterior NêO aparece de manhê (já foi liberada às 12h do dia anterior). A primeira mensagem é direto a preparaçêo às 6h45.

Blocos especiais:
- **Aula 4 (quinta):** Após ao vivo, FICHA DE INTERESSE + gravaçêo às 9h. API ficha às 12h.
- **Aula 5 (sexta):** Gravaçêo às 12h inclui reforço da ficha de interesse.

## Blocos Especiais (ambos os modelos)

### Quinta (após Aula 4):
- Ficha de interesse (grupo), SEPARADO da antecipaçêo
- Antecipaçêo Aula 5: bloco SEPARADO com bullets completos
- Ver `references/ficha-de-interesse.md`

### Sexta (modelo noite):
- 8h: gravaçêo Aula 4 + ficha de interesse EMBUTIDA no mesmo bloco
- 12h: dois blocos: 1) API ficha (com vídeo) 2) Preparaçêo texto (sem vídeo)
- 21h30: antecipaçêo com ficha no final

### Sexta (modelo manhê):
- 12h: gravaçêo Aula 5 + reforço ficha no mesmo bloco
